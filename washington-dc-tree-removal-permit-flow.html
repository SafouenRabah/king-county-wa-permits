Config Gaps to Wire Up

  1. ROW vs. private property question — not currently a field. A Tree Location field (Public ROW / Private Property) is needed to enable the private tree branch.
  2. Tree size classification — Total Tree Diameter exists but no guard logic distinguishes Special Tree (≥14" diameter / 44"+ circ) from standard. A derived field or requirement on diameter could surface the Special Tree path automatically.
  3. required_for_submission: false on all fields — core fields (Work Description, Proposed Start Date, Proposed End Date, Total Tree Diameter, Site Photos) should be marked required.
  4. Field ordering — all fields have order: null. Display order should match the logical flow above.
